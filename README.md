# Aqui Tem Tudo - Frontend Web

Este é o projeto frontend web do sistema "Aqui Tem Tudo".

## Tecnologias Utilizadas
- React (Create React App)
- React Router DOM
- Axios
- Chart.js e React ChartJS 2
- Jest e Testing Library

## Estrutura de Pastas
```
/src
  /assets         # Imagens e arquivos estáticos
  /components     # Componentes reutilizáveis
  /contexts       # Contextos globais (ex: autenticação)
  /hooks          # Hooks customizados
  /pages          # Páginas principais do sistema
  /routes         # Definição das rotas
  /services       # Serviços de API (ex: Axios)
  /utils          # Funções utilitárias
  /tests          # Testes automatizados
```

## Scripts Disponíveis
- `npm start` — Inicia o servidor de desenvolvimento
- `npm test` — Executa os testes automatizados
- `npm build` — Gera a build de produção
